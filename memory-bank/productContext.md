## Core User Journeys
1.  **Task Creation Journey:**
    *   User logs into the dashboard.
    *   User clicks the quick-add input field.
    *   User types a task name, optional tag, and presses Enter.
    *   The task immediately populates in the active view without reloading.
2.  **Task Resolution Journey:**
    *   User views the active task board.
    *   User marks a task complete.
    *   The task smoothly shifts to the history log under completed tasks.

## UX/UI Guardrails
*   **Minimalism:** Avoid multi-nested navigation windows. All primary actions must remain accessible within a single click.
*   **Predictability:** Interactive elements must display obvious hover and focus states to indicate clickability.
